## Policy and scope

The owner's November 17 v37 rule makes the pinned library the reference for generic runtime behavior. Replace the generic implementation, retain the smallest adapter that the gateway needs and remove the Bun-quirk fallback. Keep the gateway's wire, authentication, authorization, validation, persistence, resource limits, delivery and settlement contracts. Stricter generic input handling is acceptable when these contracts pass. Preserve all application outcomes and cover the supported platforms. Record generic test expectation changes with one example per component in `docs/DEVIATIONS-FROM-BUN.md`, and add a bounded robustness harness for each new library entry point.

The scope is `src/rt`, `include/uos/rt`, the HTTP adapters, the `#http` WebSocket loader, and the protocol codec slices in passkeys. HTTP session and request-body code is included in the census because it shares the parser's and writer's files. Application routing, auth/credential decisions, quota and paid ledgers, attestation trust/cache policy, and stopped-state storage custody remain with their current owners. Sparse/cyclic value repairs continue as separate cutover work. [Runtime contracts](RUNTIME.md) [Open stages](OPEN-STAGES.md)

## Work ownership and order

- **B** owns the JSON implementation and simdjson adapter (1, 17, 19), Base64 and generic crypto hex (3), and UTF slices (2). The ledger's header counts are census entries. B's resume contract controls edits to headers. JSON writer and structural cuts share one JSON writer. - **Existing pool** owns Ada URL, form and file URL (4, 5, 34), llhttp server and client (6–8), libregexp (9), OpenSSL X.509/ASN.1 (10–11), QCBOR (12, re-dispatched in v40), Beast WebSocket (13), BigInt (14) and ICU (15–16). - **Small helpers pool** owns the five briefs dispatched in v39 as one job, `cppgw-std-small-helpers-20261117`, in order date → headers → environment → filesystem → console. Its source/test pairs have ten matching preimages at the supervisor snapshot. The briefs name unique fuzz source files and exact edit ranges. Filesystem owns both rows 50–51 and retains the existing UTF interface while B changes its backend. A checks the two together after merge. The console formatter and C's terminal record construction have separate owners.
- **After current owners settle**, revisit number conversions (18) after BigInt and URI escapes (33) after B and ICU. Rebase the Beast server writer (20) after the server parser and C, the fetch writer (23) after the llhttp client and C, and multipart (30) after C releases `rt/http.cpp`. Pool briefs for these follow from the reconciled preimages. Boost.Process stays pending a qualified compiled closure (52).
- **A** owns linkage, vendor records and build/fuzz registries, including `tools/vendor_sources.py`, `cmake/vendors.json`, the relevant CMake and `fuzz/run.py` closure, and integration across v34/v39 merges.
