## Prompt admission v3 and Codex context failure encodings - 2026-11-05

Ports TypeScript `src/deepseek/forwarded-payload-policy.ts`, `src/deepseek/chat-projection.ts`, `src/codex/responses-error.ts` and `src/deepseek/context-admission-failure.ts` at the following source commits onto Rust base `a4181a3f5005adf40dcdc71ca1c87383c2b76c6a`. - `fab735ad6c3d876a74f638eedf8309e94be18ea9`: `deepseek-forwarded-payload/v2` keeps the 65,536-byte per-field cut and exempts one exact `codex-compaction-summary/v1` envelope (one user message, one `input_text` part, the 399-byte prefix with SHA-256 `e9b088e794a6bb9082ac053fcc760bd818d7e720ee4bcdc72c6e480de7b7cb0e` and a newline). Replayed reasoning keeps the generic bound (`kind: "reasoning"`, path `input[i]`), and oversized function or custom tool arguments become a parseable `gateway_elision` JSON object (`kind: "tool_arguments"`, path `input[i].arguments`). Whole-prompt admission serializes the complete projected Chat body, applies the calibrated Jev estimator (`gateway_compaction::token_estimate`) plus 256 request, 16 per-message and 32 per-tool tokens, and compares it with the profile window (DeepSeek 1,000,000, LithosAI 1,048,576, Cerebras 131,072 from the `gpt-oss-120b` hint) minus `max(16,384, max_tokens)`.
