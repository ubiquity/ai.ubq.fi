Quickstart (curl)

Try it now: (assumes $UBIQUITY_AI_USER_TOKEN is set)

curl -sS https://ai.ubq.fi/v1/chat/completions \
  -H "Authorization: Bearer $UBIQUITY_AI_USER_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{"messages":[{"role":"user","content":"Tell me a short joke."}]}'

More parameters are supported (for example model, reasoning_effort, stream, and system/developer messages). Full example: 

export UBIQUITY_AI_USER_TOKEN="..."

curl -sS https://ai.ubq.fi/health

curl -sS https://ai.ubq.fi/v1/models \
  -H "Authorization: Bearer $UBIQUITY_AI_USER_TOKEN"

curl -sS https://ai.ubq.fi/v1/chat/completions \
  -H "Authorization: Bearer $UBIQUITY_AI_USER_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{"model":"gpt-5-chat-latest","reasoning_effort":"high","messages":[{"role":"system","content":"You are a helpful assistant."},{"role":"developer","content":"Keep it concise."},{"role":"user","content":"Tell me a short joke."}],"stream":false}'
