Contact and support routing

Use the authorized operator channel associated with your UbiquityOS AI Gateway access.

Integration support

The UbiquityOS AI Gateway is a credentialed service. The correct support contact is the UbiquityOS administrator or application owner that issued the gateway token or authorized the integration. They can confirm whether an application should have access, provision or revoke a token through the protected administration workflow, and route an operational issue to the responsible team. This public page never asks you to publish, paste, or send a bearer token.

For a technical question, first read the developer portal, OpenAPI contract, and full agent guide. Include the public request ID from a response header, the endpoint, HTTP status, and a redacted error envelope when asking an authorized operator for help. Do not include prompts that contain private data, authentication headers, API keys, cookies, or upstream credentials.

Security and access concerns

If a token may have been exposed, stop using it and contact the operator who provisioned it immediately so they can revoke and replace it. If an agent does not have a token or clear authority, it must not try alternate credentials or private routes. The public health endpoint is available for release liveness; provider and administration endpoints remain protected by design.
