## Defining total operation

The owner is gateway_local_refusal::closed_error_body::ClosedErrorBody. Its private immutable fields are message: JsString16; error_type: String; code: Option<String>; param: Option<Option<JsString16>>; wire: String. No public constructor, mutable view, arbitrary raw/JSON input, Serialize/Deserialize implementation or authority token is exposed. Debug reports only byte count. Its crate-visible finite factories serve the three approved paths.

SourceRequestError::new(status: u16, message: impl Into<JsString16>, error_type: &str, code: Option<&str>, param: Option<Option<JsString16>>) -> Self stays total after its existing message conversion. SourceRequestError::from_scalar(GatewayError) -> Self stays crate-visible; from_gateway/From delegate. RoutingError::with_cleanup_diagnostic(self, &RoutingError) -> Self snapshots the scalar envelope only if there is no original body, before diagnostic mutation. Existing bodies, headers, status and private kind survive cleanup and clones.

The grammar contains only strings and explicit null, framed by fixed unique ASCII keys in order error -> message,type,code,param. There is no numeric, duplicate-key, map-order, depth, I/O, RNG or parse condition. Every string uses the one actual gateway_source::js_string::JsString16::json_token encoder; its source is unchanged. This finite frame does not copy Core ordering or introduce a generic total serializer. Ordinary allocation/process failure is not a recoverable request-domain failure or permission for a new limit.

The supplied wire type remains untrimmed; the existing scalar diagnostic still uses GatewayError::with_type. None code omits code. None param omits param; Some(None) emits null; Some(Some(text)) emits exact source text, including empty text, NUL, controls and lone UTF16 units. Neither status nor the private kind is serialized.

SourceRequestError::body now returns &ClosedErrorBody. Its borrowed views are as_str, as_bytes, message, error_type, code and param; exact signatures are in the JSON. SourceRefusalBody retains arbitrary already-validated Json(SourceJson) and InternalServerError, adding ClosedError(ClosedErrorBody). content_type is application/json for both JSON forms and text/plain; charset=utf-8 for the exact Internal Server Error bytes. Consumer header-override order remains unchanged.

into_scalar retains the old nonscalar-message/param -> original diagnostic disposition, scalar type normalization and omission/null distinction through typed observations. No new fallback exists. Only aggregate_context_overflow marks the private nonserialized kind. Ordinary constructors, same-code wire bodies, user text, untrusted Json and RoutingError::new remain false. General SourceJson parse/serialize/deserialize operations remain fallible.
