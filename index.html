Quickstart (curl)

Set a gateway token that matches the server's configured allowlist, then call the OpenAI-style routes. 

export UBQ_AI_TOKEN="..."

curl -sS https://ai.ubq.fi/health

curl -sS https://ai.ubq.fi/v1/models \
  -H "Authorization: Bearer $UBQ_AI_TOKEN"

curl -sS https://ai.ubq.fi/v1/chat/completions \
  -H "Authorization: Bearer $UBQ_AI_TOKEN" \
  -H "Content-Type: application/json" \
  --data '{"model":"gpt-5.1-codex-mini","messages":[{"role":"user","content":"Hello!"}],"stream":false}'
