# Cost evidence — DeepSeek V4.1 Flash providers (retrieved 2026-10-06)

Unit conventions: `cost.ts` returns micro-USD (1 micro-USD = 1e-6 USD). The gateway's paid ledger stores
`spend_microcredits`, and the repository's settlement path defines 1 credit = 1,000,000 microcredits = 1 USD, so
`microcredits` and `micro-USD` convert 1:1 on the paid routes.

## Retained evidence

- `cost/price-snapshot-2026-10-06.json` — live probe output for Surplus, OpenLux and OpenRouter (metadata only, no
  inference).
- `cost/raw-deepseek-pricing.html`, `cost/raw-lithos-pricing.html`, `cost/raw-lithos-billing.md` — the published pricing
  pages the rate card cites.
- `cost/raw-openlux-ratio.json` — the ratio configuration the OpenLux math is derived from.
- `cost/raw-lithos-models.json`, `cost/raw-lithos-models-doc.md`, `cost/raw-lithos-model-detail.json`,
  `cost/raw-lithos-llms.txt` — the negative evidence that the Lithos API publishes no prices.
- `cost/raw-openlux-logs.json` — the token-log endpoint shape used for observed OpenLux billing.

## Readback commands for the benchmark instance

```sh
curl -s http://127.0.0.1:7998/admin/providers/quota-projection?window_days=7   # per-model usage + spend_microcredits
curl -s http://127.0.0.1:7998/admin/kernel-usage                              # paid-ledger rollups and settlement state
```
